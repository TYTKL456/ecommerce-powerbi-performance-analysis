# Requirements

- Windows and Power BI Desktop, with support for the supplied PBIX format.
- `Orders.csv` and `Details.csv` (included).
- Sufficient permission to read the local data files. Update source paths in Power Query when required.

No Python installation or `requirements.txt` is needed to open the Power BI report. The original analysis document mentions Matplotlib and Seaborn, but no Python scripts or Python dependency manifest were present in the supplied project folder.
